# 학습 기록 양식

아래 내용을 `_posts/YYYY-MM-DD-topic.md`로 복사하고 날짜와 제목을 바꿉니다.

```yaml
---
layout: post
title: "학습 주제"
description: "이번에 직접 확인한 내용을 한 문장으로"
date: YYYY-MM-DD 00:00:00 +0900
---
```

## 학습 질문

이번 실험으로 무엇을 확인하려고 했는가?

## 실험 조건과 방법

사용 도구·모델·버전, 입력, 지시문, 실행 방법을 적습니다.

## 결과

실제 출력과 화면, 예상과 달랐던 점을 적습니다.

## 내가 판단하고 수정한 부분

AI 제안 중 선택하거나 버린 내용과 그 이유를 적습니다.

## 배운 점

실험 결과로 뒷받침되는 내용을 적습니다. 추측은 추측으로 표시합니다.
