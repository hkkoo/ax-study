# Agentic BSP 시리즈 재구성 기록

- 검토 기준: AGY main `c7c7cae` (2026-10-18), 후속 편 링크와 5편 추가까지 포함.
- 작업 위치: `codex/agentic-bsp-series` 전용 worktree.
- 목적: BSP 업무의 agentic 전환과 기존 방식 대비 KPI 측정을 시리즈 전체의 공통 축으로 정리.
- 문서 상태: 설계 제안. 실제 BSP 파일럿의 성과나 ROI 측정값은 아직 없음.

## 유지한 내용

공개 사례를 근거로 설명하는 1편, 5대 공통 기반, 호스트부터 제한된 범위로 시작하는 접근을 유지했다. AGY의 5편에서 추가한 A/B/C 비교, 복구에 든 사람 시간, 전체 소요시간, 재작업과 총비용을 전 편의 공통 측정으로 연결했다. 기존 게시물 파일명과 URL도 유지했다.

## 변경한 흐름

1. 문제·대상 업무·기준선·완료 기준을 먼저 정한다.
2. Profile·Skill·관측·검증·실행 기록의 계약을 만든다.
3. 호스트 업무 하나를 끝까지 수행하고 기준선과 비교한다.
4. 과제의 하드웨어 의존성에 맞게 DUT를 선택해 런타임 가설을 검증한다.
5. 확인된 흐름을 CI·실물 DUT 운영에 연결하고 KPI·총비용으로 확장 여부를 정한다.

L1~L6은 능력을 설명하는 보조 틀로 남겼다. 가상 DUT·실물 DUT·CI·다중 에이전트를 단일 승급 순서로 연결하지 않는다. 공통 목차는 `_includes/agentic-bsp-series.md`에서 유지한다.

## 주요 교정

- Cuttlefish의 Framework 검증 범위와 제품 HAL·하드웨어 차이를 구분했다.
- QEMU의 머신·장치 모델 및 호환되는 커널 조건을 명시했다.
- 런타임 사례에서 기본 테이블처럼 제시했던 가상 스키마를 제거하고 실제 `android_logs` 탐색 예시를 사용했다.
- AVC denial을 곧바로 Device Tree나 정책 누락의 확정 증거로 취급하지 않는다.
- Profile의 선언과 실제 타깃·이미지의 관측을 분리하고 `unknown`과 판정 불가를 보존한다.
- 파티션 이름만으로 자동 플래시를 허용하지 않으며, 승인·타깃·산출물 해시·점유·복구를 실행 정책에 연결한다.
- 고정된 해결·절감 목표 수치 대신 분모·평가 기간·과제량·검증 범위를 정의했다.
- 승인만 받은 실행과 무개입 자율 완료를 구분하고, 비용의 중복 집계를 피한다.
- 존재하지 않는 계획 문서 링크와 측정하지 않은 속도·복원력·완료율 주장을 제거했다.

## 검증

- `git diff --check`: 통과.
- 사용자 전용 의존성 경로를 지정한 `bash docs/jekyll-local.sh build`: 통과.
- 기존 `docs/check-site.cjs`: 통과 (홈·소개·내부 링크·기존 페이지 회귀·반응형 검사).
- 시리즈 전용 브라우저 확인: 다섯 글의 단일 제목, 공통 목차, 다섯 목적지의 HTTP 응답, Liquid 렌더링, 1440/768/390/320px 가로 넘침 검사 통과.
- AGY 독립 스냅샷 리뷰: 1차 의견 중 비용의 기간·과제량, 승인 정책 표현, A/B/C 안내와 SQL 제한 설명을 보완했다. 최종 스냅샷 재검토에서 중대한 기술적 모순이나 KPI 결함이 없다는 판정을 받았다. 텍스트 검토이며 BSP 실행 검증을 뜻하지 않는다.

문서 빌드·브라우저 검사는 BSP 도구 실행이나 보드 검증을 수행한 결과가 아니다. 다음 실제 실험은 과제군 하나를 고른 A/C 비교 파일럿이다.
