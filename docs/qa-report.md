# 포트폴리오 홈 개편 검증

## 결과

로컬 구현 및 검증 완료. 이 보고서는 배포 전 로컬 검증 결과이며,
GitHub 배포 성공 여부는 해당 커밋의 Pages 작업 결과로 별도 확인합니다.
실험 자체는 기획 단계이며, 실제 실행 결과나 성과 수치를 만들어 넣지 않았습니다.

## 검증한 항목

- Jekyll 실제 빌드 성공 (`bash docs/jekyll-local.sh build`).
- 셸 설정을 제거한 `env -i` 환경에서도 로컬 실행 도우미로 빌드 성공.
- 개인 프로젝트·업무 자동화·학습/조사·전체 필터와 항목 수 일치.
- 추가 항목을 넣은 별도 4개 프로젝트 fixture에서 전체 수·분류별 수 회귀 검사 통과.
- 밝은/어두운 테마 전환 및 새로고침 후 저장 상태 유지.
- 첫 키보드 Tab에서 본문 바로가기, Enter 후 본문 포커스 이동.
- 1440·768·390·320px에서 홈 가로 넘침 없음.
- 소개 및 실험 노트는 320px에서도 가로 넘침 없음.
- 홈에서 연결된 내부 페이지 HTTP 200, 내부 앵커 대상 존재.
- 검사 중 JavaScript 페이지 오류 없음.
- JavaScript 및 Bash 구문 검사, `git diff --check` 통과.
- 독립 코드 검토: 차단할 보안 문제나 동작 회귀 없음.

## 수정한 회귀

- 프로젝트 수가 바뀌어도 현황 및 분류 배지가 갱신되도록 정적 숫자를 Liquid 계산으로 교체.
- 키보드 사용자를 위한 본문 바로가기 추가.
- 최소 환경에서 Ruby/Bundler 재실행 시 US-ASCII로 돌아가던 빌드 오류를 도우미의 UTF-8 로케일로 해결.

## 도구 및 제한

Ruby 3.3, Bundler, GitHub Pages 의존성, Playwright 및 Chromium을 사용자 전용
디렉터리에 설치했습니다. 관리자 권한이나 셸 시작 파일 수정은 사용하지 않았습니다.
빌드 시 Faraday의 선택적 retry middleware 안내가 출력되지만 빌드 종료 코드는 0입니다.
GitHub 원격 배포, 외부 링크 가용성 전체 점검, 모든 브라우저 엔진 및 정식 접근성 감사는 범위 밖입니다.

브라우저 재검증 명령과 로컬 빌드/서버 명령은 README.md를 참고하세요.
